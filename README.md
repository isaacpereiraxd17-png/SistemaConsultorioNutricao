# Sistema de Consultório de Nutrição

## Status do Projeto
> Em desenvolvimento

## Tecnologias Aplicadas
- **Linguagem:** Java (versão padrão desktop com componentes Swing)[cite: 3, 4]
- **Banco de Dados:** MySQL[cite: 3, 4]
- **Ferramenta de Build:** Apache Ant[cite: 1]

## Time de Desenvolvedores
- Aluno / Desenvolvedor Responsável (Equipe do Projeto Integrador)

## Objetivo do Software
O sistema tem como objetivo otimizar o fluxo de atendimento em consultórios de nutricionistas, permitindo o gerenciamento centralizado de pacientes, o controle de agendamento de consultas e o acompanhamento de fichas de avaliação física e nutricional (com cálculo automático de IMC)[cite: 3].

## Funcionalidades do Sistema (Requisitos)
- **RF01:** Cadastro, edição, listagem e exclusão de Pacientes (nome, CPF, telefone e idade)[cite: 2, 4].
- **RF02:** Agendamento, listagem, atualização e exclusão de Consultas (data, status de realização, receita e vínculo com paciente)[cite: 2, 4].
